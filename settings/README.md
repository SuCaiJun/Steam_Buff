# Settings 设置中心

## 功能说明

Settings 负责扩展设置页面、账号状态、会员门控、更新提示和设置存储。

## 目录结构

```text
settings/
├── api/        # 设置域请求封装
├── menu/       # 菜单与分类
├── pages/      # 设置页面
├── panels/     # 设置面板
├── ui/         # 设置 UI 组件和样式
├── storage.js
└── catalog.js
```

## 菜单结构

左侧菜单固定顺序：用户中心、扩展设置、商店增强、社区增强、评论过滤、客户端增强、翻译相关、Ai服务设置、第三方相关、关于。

- `扩展设置` 只放设置中心自身选项。
- `商店增强` 承载商店详情提醒检查、价格相关增强、愿望单、数据展示、智能搜索、标题中文名和购物车增强。
- `社区增强` 当前保留为空页，后续只放一方社区增强能力。
- `评论过滤`、`翻译相关`、`Ai服务设置` 的总开关在各自页面顶部，不控制左侧菜单显隐。
- `第三方相关` 承载库存增强和消费历史分类器；库存增强继续使用 `market-tools` 设置 key。

## 注意事项

- 请求统一走 `settings/api/request.js`。
- 非会员禁用 UI 时只禁用交互，不清空用户配置。
- UI 应复用现有 field、switch、toast、dialog 等组件和 `STTheme.cssVariables`。
