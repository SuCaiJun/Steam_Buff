自定义名称

选择自定义名称方案

我要赞助开发者

按使用场景对比两种方案，选择适合自己的名称管理方式。

此处选择库列表的名称方案，不影响已开通的商店和愿望单功能。

免费版是基于 Steam 的自定义排序名称实现的，将数据保存至 Steam 的自定义排序名称中。使用需要将需要显示的名称写在自定义排序名称中，库列表会自动显示该名称。

捐赠版为独立实现，将自定义名称数据存储至素材君服务器中，自定义名称数据与素材君账号绑定，不影响也不会干扰 Steam 的自定义排序名称功能的使用。

无论使用哪种方案，在重装或换设备时，已同步到云端的数据可通过原账号恢复。切换方案不会迁移或删除已保存的名称。

价格数据服务

为历史价格和折扣预测连接数据源。密钥由你自己申请。

  1. 申请自己的 ITAD API Key
  2. 粘贴到下方
  3. 测试通过后保存
怎样获取 API Key？
  1. 打开 IsThereAnyDeal 应用页面，注册或登录账号。
  2. 按网站要求注册应用，获取 API Key。
  3. 复制 API Key，回到本页粘贴并测试连接。
